# Changelog

## 1.1.0 — 2026-11-11

- Adjust the floating window's transparency instantly from 0% to 70% with a slider below the editor.
- Restore a fully opaque window with Reset or the tray's Reset transparency action.
- Keep transparency when hiding and reopening the window; start fully opaque in a new session.
- Preserve native resizing and clipboard selection while adjusting transparency.
- Build and test into a separate output folder while an earlier version is running.

## 1.0.0 — 2026-11-11

- Temporary history of up to 20 text, image, and file clips.
- Floating window, text editing, search, pinning, pause, and tray controls.
- Global show/hide shortcut with automatic fallback.
